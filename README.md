# conta-rizoma4

Módulo doctrinal del PGC español para Rizoma4.

## Qué es

`conta-rizoma4` es un paquete Python que implementa la contabilidad
como **acto de clasificación justificado por el PGC**, no como cuaderno
de cuentas. Cada asiento puede trazarse a un párrafo del Plan General
de Contabilidad (párrafo 4: "se atenderá a su realidad económica y no
sólo a su forma jurídica").

Es cliente de `rizoma4` (el kernel epistémico). `rizoma4` no sabe que
existe `conta-rizoma4`. `conta-rizoma4` sí sabe que existe `rizoma4`.
